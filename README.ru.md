# MathPaperLib

[English version](README.md)

MathPaperLib хранит статьи, с которыми вы работаете, в одной папке, `~/Literature`, под именами
вида `Bondarenko 2021 - Inverse spectral problems for functional-differential operators with involution.pdf`
и даёт ИИ-агенту инструменты, чтобы находить статьи, скачивать их, читать по страницам и искать
по полным текстам. Инструменты доступны как MCP-сервер, который запускает любая агентская
обвязка с поддержкой MCP, и как команда `lit`.

arXiv и Math-Net.Ru отдают файлы под идентификаторами (`2107.12209v1.pdf`, `rm9740.pdf`), и
папку загрузок глазами не прочесть. PDF, сохранённый вручную с сайта издательства, сохраняет
имя, данное сайтом, а инструмент, скачавший остальные статьи, о нём не знает. Если каждый проект
держит свои статьи, статья, нужная двум проектам, скачивается и индексируется дважды.

MathPaperLib ведёт одну библиотеку на пользователя. Каждая статья хранится в ней один раз, под
именем из авторов, года и названия. PDF, скачанный вручную, кладётся в папку inbox: там его
опознают по первым страницам и называют по тому же правилу. Проект хранит только реестр — список
нужных ему статей с их ролью, — а файлы берёт из библиотеки. Полнотекстовый поиск идёт по
LaTeX-исходникам и текстовым слоям PDF; он сочетает BM25 с многоязычной моделью эмбеддингов
`intfloat/multilingual-e5-small`, которая работает на процессоре.

## Библиотека

```
~/Literature/
  Bondarenko 2021 - Inverse spectral problems for functional-differential operators with involution.pdf
  Bondarenko 2021 - Inverse spectral problems for functional-differential operators with involution.tex
  Shkalikov 2016 - Vozmushcheniya samosopryazhennykh i normalnykh operatorov s diskretnym spektrom.pdf
  library.json
  inbox/
  .lit/
```

В `library.json` записаны метаданные каждой статьи, её идентификаторы (arXiv, DOI, Math-Net.Ru),
имена её файлов и их контрольные суммы SHA-256. В `.lit/` лежит то, что получено из статей:
текстовые слои PDF, страницы в PNG, части транскрипций и поисковый индекс. Чтобы держать
библиотеку в другом месте, задайте `MATHPAPERLIB_HOME` или передайте `--library`.

Файл называется `Authors Year - Title`. Один или два автора перечисляются по фамилиям, при трёх и
более пишется `First et al.`; год берётся из метаданных, а если его там нет — из номера arXiv.
Кириллица транслитерируется, диакритика снимается, поэтому имя состоит из ASCII. Символы,
запрещённые в именах файлов Windows, macOS или Linux, заменяются; имя длиннее 140 знаков
обрезается по слову, а к занятому имени добавляется ` (2)`. Имя даётся, когда статья попадает в
библиотеку, и потом не меняется.

## Inbox

Положите скачанный PDF в `inbox/` и запустите `lit inbox` или попросите агента вызвать
инструмент `inbox`. Идентификатор ищется в таком порядке: номер arXiv в имени файла, номер arXiv
в тексте первых двух страниц, DOI в том же тексте. Первый DOI на странице может принадлежать
цитируемой статье, поэтому идентификатор принимается, только если не меньше 60 % слов названия
длиной от четырёх букв встречаются на этих страницах. Принятый файл переходит в библиотеку под
своим именем и индексируется; в проекте он ещё прикрепляется к записи реестра с тем же
идентификатором, если у записи файла пока нет. Неопознанный файл остаётся в inbox, и в отчёте
названа причина; `lit inbox FILE --id DOI` берёт его под указанным идентификатором.

## Проекты

Проект — папка, где есть `sources/papers.json` или таблица `[sources]` в `project.toml`. Его
реестр даёт каждой статье код `S1, S2, …`, роль статьи в проекте, проверенное описание и статус
её карточек теорем; `lit catalog` собирает из реестра `sources/catalog.md`. Поиск внутри проекта
ограничен статьями его реестра. Все ключи таблицы необязательны:

```toml
[sources]
registry = "sources/papers.json"
catalog = "sources/catalog.md"
cards = "sources/cards"            # карточки теорем S*.md, `verified:` в заголовке
results = "sources/results.md"
library = "output/literature"      # библиотека только этого проекта
direct_hosts = ["mathnet.ru"]      # хосты, к которым идём мимо VPN-туннеля
```

Запрос к хосту из `direct_hosts` уходит с адреса сетевого интерфейса вне маршрута по умолчанию,
то есть мимо VPN-туннеля; по умолчанию в списке `mathnet.ru`.

Проект берётся из `--root`, иначе из `MATHPAPERLIB_PROJECT`, иначе это ближайший проект вверх от
текущей папки. С `--no-project` или когда проект не найден инструменты работают с одной
библиотекой; MCP-инструмент `use_project` выбирает проект по ходу сессии.

Проект, сделанный с `lit.py` исследовательского шаблона AutoMath, держит файлы в
`output/literature/` под именами-идентификаторами. `lit migrate` копирует их в библиотеку под
новыми именами вместе с текстовыми слоями и частями транскрипций и переписывает реестр. Старая
папка остаётся, пока вы её не удалите; с `--move` файлы переносятся.

## Установка

Пакет запускается через [uv](https://docs.astral.sh/uv/). Первый полнотекстовый поиск скачивает
модель эмбеддингов с Hugging Face, около 470 МБ.

Командная строка:

```
uv tool install git+https://github.com/LeoLourson/MathPaperLib
lit where
```

MCP-сервер запускается командой
`uvx --from git+https://github.com/LeoLourson/MathPaperLib mathpaperlib mcp` и общается через stdio.

- Claude Code: `/plugin marketplace add LeoLourson/MathPaperLib`, затем
  `/plugin install mathpaperlib@mathpaperlib`. Плагин добавляет MCP-сервер и два скилла,
  `literature` и `transcribe-paper`.
- DSH: бандл `dsh-mathpaperlib` лежит в [`dsh/`](dsh/). Его ссылкой кладут в `node_modules`
  профиля и добавляют в `dependencies` и в `dsh.profile.bundles`. Он добавляет MCP-сервер, оба
  скилла и раздел системного промпта с путём библиотеки и числом PDF, ждущих в её inbox. Чтобы
  запускать локальную копию вместо версии с GitHub, переопределите в патче профиля запись
  `mcp-mathpaperlib`: `command: uv`, `args: [run, --directory, <checkout>, lit, --no-project, mcp]`.
- Codex, в `~/.codex/config.toml`:

  ```toml
  [mcp_servers.mathpaperlib]
  command = "uvx"
  args = ["--from", "git+https://github.com/LeoLourson/MathPaperLib", "mathpaperlib", "mcp"]
  ```

- Другой MCP-клиент: та же команда. Скиллы в [`skills/`](skills/) — обычные файлы `SKILL.md`;
  скопируйте их туда, где обвязка читает инструкции, или в `AGENTS.md`.

## Команды

| Команда | Что делает |
| --- | --- |
| `find "запрос" [--in zbmath\|arxiv\|mathnet\|crossref\|openalex\|s2\|all]` | кандидаты с аннотациями; статьи, которые уже есть в проекте или библиотеке, помечены |
| `doi 10.xxxx/...` | журнал, том, страницы, авторы, аннотация, открытый PDF |
| `cites REF [--refs]` | кто цитирует статью, или её список литературы |
| `add ID... [--role "..."]` | скачать в библиотеку; в проекте ещё и внести в реестр, где роль обязательна |
| `inbox [FILE...] [--id ID]` | разобрать PDF из inbox |
| `attach REF FILE` | прикрепить файл, полученный вручную |
| `add-file FILE --title --authors --version --url` | добавить статью без номера arXiv, DOI и номера Math-Net.Ru |
| `search "запрос" [--code S4] [--kind theorem]`, `show N [-n 1]` | поиск по полным текстам; кусок по номеру вместе с соседями |
| `pdf REF`, `pages REF [--range 3-10]` | PDF; страницы в PNG с текстовым слоем |
| `parts REF`, `tex REF [--build]` | транскрипция PDF в LaTeX по частям, затем сборка и проверка pdflatex |
| `annotate FILE.json`, `audit` | описания статей проекта и их проверка |
| `fetch [CODE...]`, `catalog`, `index` | восстановить недостающие файлы, пересобрать каталог, проиндексировать новые тексты |
| `list`, `library`, `where` | статьи проекта, опись библиотеки, действующие пути |
| `migrate [--from DIR] [--move]` | перенести проект старой раскладки в библиотеку |
| `mcp` | MCP-сервер на stdio |

`REF` — код реестра (`S4`), идентификатор или начало имени файла в библиотеке. MCP-сервер
предлагает те же действия как инструменты.

## Границы

Скачиваются только открытые копии: исходники и PDF с arXiv, PDF с Math-Net.Ru, если полный текст
там открыт, и PDF открытого доступа, который OpenAlex знает для DOI. Для остальных статей `add`
записывает метаданные, а PDF приходит через inbox или `attach`.

Inbox узнаёт статью только по номеру arXiv или DOI. Скан без текстового слоя и статья, на первых
двух страницах которой нет ни того ни другого, остаются в inbox, пока их не назовут через `--id`.

Названия транслитерируются, а не переводятся: статья на русском получает русское название
латиницей, даже когда английское название известно. Автор, записанный одними инициалами,
попадает в имя этими инициалами.

Сообщения инструмента — на русском; описания MCP-инструментов и скиллы — на английском.
